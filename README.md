# Concert-Connect (ConcierGo)

Turborepo **React + Vite** + **Express** + Neon + Clerk. Un deploy en Vercel.

```bash
cp .env.example .env
pnpm install
pnpm api          # Express :3001
pnpm start        # Vite :5173 → proxy /api
```
