# Front en Conciergo

Este repo **no** usa Angular. El cliente es **React + Vite + Tailwind 4 + shadcn**. La skill Angular de Task Cloud no aplica.

## Qué se aplica

| Práctica | Dónde |
|----------|--------|
| Wouter | Rutas (`/events`, `/events/map`, `/matches`, `/profile`) |
| React Query | Listados y estado de sesión |
| Neon Auth | Landing signed-in → redirect `/events` |
| Framer Motion | Landing y cards |
| Bottom nav + sidebar | `app-layout.tsx` (móvil / desktop) |

## Por qué está este doc

La suite featured `01`–`11` se llama igual que en Task Cloud / Presencia. Aquí el “11” documenta el **techo real del front** para no fingir un stack Angular.
